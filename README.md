# Waiting for Closure — project page

Static project page for *Waiting for Closure: Deep Networks Integrate Contours Locally but Do Not Perceive Illusory Closure*.

`index.html` is generated by `build_site.py` from the paper source (text, captions, numbers and the all-network table are lifted from the TMLR LaTeX, so the page cannot drift from the paper). Figures are in `fig/`, the paper PDF in `paper/`.
